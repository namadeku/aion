# Aion

Голосовой ассистент для рабочего стола в духе J.A.R.V.I.S. Просыпается по имени, понимает
русскую и английскую речь, выполняет команды через плагины, свободно разговаривает
с помощью языковой модели, отвечает выбранным голосом и показывает анимированного аватара,
который двигает губами, когда говорит.

**Всё может работать офлайн**: распознавание (Whisper / Vosk), синтез речи (Piper / Silero) и
языковая модель (Ollama). Облачные сервисы (Claude, OpenAI, Edge TTS) подключаются по желанию.

- 🎙 Активация по имени, которое можно сменить на лету («теперь тебя зовут Пятница»), без обучения модели
- ⚡ Ответ начинает звучать, пока модель ещё пишет: стриминг LLM и синтез по предложениям
- 🔌 Плагины: команды на русском, инструменты для LLM, горячая перезагрузка, настройки в интерфейсе
- 🧰 MCP: подключите любой MCP-сервер (файлы, браузер, календарь…) — его инструменты станут навыками
- 👁 Видит экран: «что у меня на экране», «переведи текст на экране» — локальной vision-моделью
- 🎮 Комментирует игры: CS2, Dota 2 и Valorant — мультикиллы, раунды, итог матча (официальные интеграции, без риска бана)
- 🧠 Память: факты о вас и дневник прошлых разговоров — сама спросит, как прошло собеседование
- 💬 Живой характер: настроение (энергия, симпатия, скука) меняет тон и анимацию; сама заговаривает после долгой тишины, здоровается, напоминает о перерыве
- 🗣 Голоса Piper, Silero, Edge TTS, клонирование голоса XTTS; «металлический» эффект
- 🧑‍🚀 3D-аватар VRM, Live2D или голографический HUD-круг; липсинк, эмоции, жесты и idle-анимации
- 🖥️ Режим рабочего стола: персонаж выходит из окна, гуляет по панели задач и сидит на окнах
- 🖥 Тёмный HUD-интерфейс в отдельном окне, иконка в трее, горячая клавиша «нажми и говори»

## Установка

Нужны Windows 10/11 (64 бит), интернет во время установки и около 3 ГБ на диске
(с Ollama и её моделью — ещё около 7 ГБ). Больше ничего ставить заранее не нужно.

1. Скачайте `Aion-Setup-<версия>.exe` со страницы
   [последнего релиза](https://github.com/namadeku/aion/releases/latest).
2. Запустите его. Права администратора не нужны: Aion ставится в
   `%LOCALAPPDATA%\Programs\Aion`, ярлыки появятся в меню «Пуск» и (по желанию) на рабочем столе.
   Если Windows SmartScreen предупредит о неизвестном издателе, нажмите «Подробнее» →
   «Выполнить в любом случае».
3. Установщик сам скачает (с прогрессом) всё, чего не хватает: модели распознавания и голоса
   (около 550 МБ), Microsoft Edge WebView2 для окна программы, если его нет, и — если оставить
   галочку — [Ollama](https://ollama.com) для свободного разговора.
4. При первом запуске окно откроется сразу. Если что-то ещё не скачано (не было интернета при
   установке, или это языковая модель qwen3:8b для Ollama, около 5 ГБ), карточка в окне
   покажет, что и сколько качается; писать текстом можно уже в это время.

**Видеокарта NVIDIA.** Установщик содержит версию для процессора. Если в компьютере есть
видеокарта NVIDIA, на странице «Микрофон» появится кнопка «Скачать» для библиотек CUDA
(около 1,4 ГБ): с ними распознавание речи станет быстрее и точнее.

**Языковая модель для разговора.** По умолчанию — qwen3:8b в Ollama: хорошо говорит
по-русски, но для неё желательны 16 ГБ памяти или видеокарта. Без Ollama команды работают,
а для разговора можно подключить Claude или любой OpenAI-совместимый API на странице «LLM».

## Обновление

Aion сам проверяет обновления при запуске и сообщает о новой версии. Обновить можно на
странице «О программе»: кнопка «Обновить и перезапустить» скачает новую версию, установит её
и запустит заново. Настройки, модели, история и память при этом сохраняются. Автопроверку
можно выключить там же.

## Удаление

«Параметры» → «Приложения» → «Установленные приложения» → Aion → «Удалить» (или `unins000.exe`
в папке программы). Деинсталлятор спросит, удалить ли также настройки, скачанные
модели и историю (`%LOCALAPPDATA%\Aion`); если отказаться, они останутся для следующей
установки.

## Первый запуск

Запустите Aion ярлыком. Откроется окно Aion, и ассистент поздоровается. Дальше:

- скажите **«Аион, который час?»** — имя и команда одной фразой;
- или **«Аион»**, дождитесь короткого сигнала и говорите команду;
- после ответа несколько секунд можно продолжать без имени;
- чтобы перебить ассистента, назовите его по имени;
- **Ctrl+Alt+Space** — «нажми и говори» без имени;
- в окне можно писать текстом.

Что попробовать:

| Фраза | Что произойдёт |
|---|---|
| «Поставь таймер на пять минут», «напомни через час позвонить маме» | Таймеры и напоминания (переживают перезапуск) |
| «Какая погода в Казани», «нужен ли зонт» | Погода (Open-Meteo, без ключа) |
| «Открой телеграм», «открой загрузки», «найди рецепт борща» | Программы, папки, поиск |
| «Сделай потише», «следующий трек», «сделай скриншот» | Управление компьютером |
| «Сколько будет 17 умножить на 23», «100 долларов в рублях» | Калькулятор и валюты |
| «Запомни, что я пью кофе без сахара», «что ты обо мне знаешь» | Долговременная память |
| «Добавь в список дел оплатить интернет» | Заметки и дела |
| «Прочитай, что скопировано», «переведи скопированное на английский» | Буфер обмена |
| «Что ты умеешь?» | Список навыков |
| Любой вопрос | Ответ языковой модели (с инструментами из плагинов) |

## Настройка

Почти всё настраивается в интерфейсе. Настройки сохраняются в
`%LOCALAPPDATA%\Aion\config.yaml`. Там же лежат
модели, база данных, установленные плагины, логи и `.env` с ключами API.

### Имя

Скажите **«Теперь тебя зовут Пятница»** или поменяйте имя на странице «Голос и персонаж».
Новое имя работает сразу, без перезапуска. Если распознаватель слышит имя иначе (например,
«Джарвис» как «Джарвиз»), добавьте варианты произношения в поле рядом.

### Голос

Страница «Голос и персонаж»: движок, голос (кнопка «Прослушать»), скорость, высота тона,
эффект «металлический».

| Движок | Особенности |
|---|---|
| **Piper** (по умолчанию) | Быстрый, офлайн, голоса Денис, Дмитрий, Руслан, Ирина |
| **Silero** | Самые естественные русские голоса, офлайн. Только при установке из исходников (нужен torch) |
| **Edge TTS** | Онлайн, десятки голосов, бесплатно |
| **XTTS** | Клон голоса по 6–30 с записи; только при установке из исходников, нужна видеокарта |

### Аватар

На странице «Голос и персонаж» → «Аватар» выберите тип и укажите путь к файлу:

- **VRM** (`.vrm`): сделайте персонажа в [VRoid Studio](https://vroid.com/studio) или скачайте на [VRoid Hub](https://hub.vroid.com).
- **Live2D** (`.model3.json`): положите рядом с моделью `live2dcubismcore.min.js` из
  [Cubism SDK for Web](https://www.live2d.com/sdk/download/web/) (по лицензии Live2D его нельзя распространять вместе с Aion).
- **HUD**: голографический круг, реагирующий на голос (по умолчанию).

### Персонаж на рабочем столе (Windows)

Кнопка с монитором на главной странице или пункт «Персонаж на рабочем столе» в трее: окно
скрывается, а персонаж появляется поверх рабочего стола. Она гуляет по панели задач, садится
на верхний край окон и едет вместе с ними, падает, если окно закрыли или свернули, следит
взглядом за курсором и показывает реплики в облачке.

- перетащите её мышью и бросьте — упадёт на панель задач или на окно;
- клик — «тык», провести курсором по голове — погладить;
- двойной клик — вернуть в окно, правый клик — меню («Поговорить», «Открыть окно»).

Рост персонажа задаётся в «Голос и персонаж» → «Аватар» (`ui.desktop_scale`).

### Персонажи

Профиль — это имя, голос, аватар и характер (системный промт) вместе. Создайте несколько
профилей (вежливый дворецкий, весёлая напарница…) и переключайтесь между ними.

### Распознавание и микрофон

Страница «Микрофон»: выбор устройства, индикатор уровня, способ активации и чувствительность,
перебивание, модель Whisper. На видеокарте NVIDIA по умолчанию используется `large-v3-turbo`
(точная и быстрая, ~0,3 с на фразу), на процессоре — `small`.

Если ассистент срабатывает на посторонние разговоры, уменьшите чувствительность. Если плохо
слышит имя, увеличьте её или добавьте варианты произношения.

### Языковая модель

Страница «LLM»: Ollama (офлайн), Claude или OpenAI-совместимый API (OpenAI, LM Studio, vLLM,
OpenRouter). Ключи API вводятся там же и сохраняются в `%LOCALAPPDATA%\Aion\.env`, не в
репозитории. Кнопка «Проверить» показывает, отвечает ли модель и за сколько.

## Плагины

Плагины устанавливаются на странице «Плагины» (папка, .zip или git-URL) и подключаются без
перезапуска. Как написать свой плагин — в [docs/PLUGINS.md](docs/PLUGINS.md).

## Сборка из исходников

```powershell
git clone https://github.com/namadeku/aion
cd aion
uv sync --extra cloud                   # + --extra cuda для видеокарты NVIDIA
cd frontend; pnpm install; pnpm build; cd ..
uv run aion run                         # запуск без установки
uv run python scripts/build_installer.py   # установщик в dist\ (нужен Inno Setup)
```
