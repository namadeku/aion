# Плагины Aion

Плагин — это папка с двумя файлами: `plugin.yaml` (описание) и `main.py` (код).
Ассистент находит плагины сам, перезагружает их при сохранении файла, а ошибка в одном
плагине не роняет ни ассистента, ни другие плагины.

## Быстрый старт

```powershell
uv run aion plugin new hello
```

Команда создаст `%LOCALAPPDATA%\Aion\plugins\hello\` с рабочим шаблоном. Отредактируйте
`main.py` и сохраните файл: если Aion запущен, плагин перезагрузится сам. Скажите
«Aion, тест hello».

Минимальный плагин:

```python
# main.py
from aion.sdk import Context, Plugin, command


class Hello(Plugin):
    @command(["привет", "привет {name}"])
    async def hello(self, ctx: Context, name: str = "") -> None:
        await ctx.say(f"Здравствуйте, {name or ctx.user_address}!")
```

```yaml
# plugin.yaml
name: hello
title: Приветствие
version: 0.1.0
```

## Где лежат плагины

| Папка | Что там |
|---|---|
| `src/aion/plugins/builtin/` | Встроенные плагины (это обычные плагины, их код — хороший пример) |
| `%LOCALAPPDATA%\Aion\plugins\` | Установленные плагины (`aion plugin install`, `aion plugin new`) |
| `plugins.dirs` из `config.yaml` | Дополнительные папки, по умолчанию `./user_plugins` |

При совпадении имён побеждает плагин из более поздней папки, поэтому встроенный плагин можно
заменить своим.

## plugin.yaml

```yaml
name: weather_plus            # обязательно: латиница в нижнем регистре, цифры, _
title: Погода+                # для интерфейса
version: 1.2.0
author: Иван Петров
description: Подробный прогноз и уведомления о дожде.
entry: main.py                # по умолчанию main.py
class: WeatherPlus            # если в файле несколько классов Plugin
dependencies:                 # pip-пакеты, ставятся автоматически
  - requests>=2.31
permissions: [network]        # network, system, shell, files, clipboard, notifications
enabled_by_default: true      # false — пользователь включит сам (например, нужен токен)
settings:                     # интерфейс сам нарисует форму, см. «Настройки плагина»
  city:
    type: string
    title: Город
    default: Москва
```

## Команды: `@command`

```python
@command(patterns, *, name=None, dangerous=False, priority=0, description="")
```

Обработчик — асинхронный метод `async def handler(self, ctx, **слоты)`.

### Синтаксис шаблонов

| Запись | Значение | Пример |
|---|---|---|
| `слово` | точное слово | `который час` |
| `{slot}` | слот, передаётся аргументом | `погода в {city}` |
| `(а\|б)` | один из вариантов | `(открой\|запусти) {app}` |
| `[слово]` | необязательное слово | `[какая] погода` |
| `[а\|б]` | необязательный вариант | `прибавь [громкость\|звук]` |

Фразы сравниваются после нормализации: регистр, «ё», знаки препинания не важны, а числа
словами переводятся в цифры («двадцать пять» → `25`). Тип слота задаётся аннотацией:

```python
@command("(поставь|заведи) таймер на {minutes} минут")
async def timer(
    self, ctx: Context, minutes: int
) -> None:  # int/float-слот совпадает только с числом
    ...
```

### Как выбирается команда

1. Точное совпадение шаблона: 100 баллов.
2. Совпадение с лишними словами в начале («Aion, скажи, пожалуйста, который час»): 97 минус 2 за слово.
3. Нечёткое совпадение (опечатки и ошибки распознавания, rapidfuzz) — если выше порога `plugins.fuzzy_threshold` (82).
4. При равенстве: выше `priority`, затем шаблон с бо́льшим числом обычных слов.
5. Ничего не подошло — фраза уходит в LLM.

### Отказ от фразы

Если обработчик вернул `False`, фраза идёт к следующей подходящей команде, а потом в LLM.
Так широкий шаблон не перехватывает чужие фразы:

```python
@command("включи {device}", priority=1)
async def turn_on(self, ctx: Context, device: str) -> bool:
    if device not in self.devices:
        return False  # пусть «включи телеграм» обработают «Программы»
    ...
    return True
```

### Перехват любой фразы

```python
async def on_utterance(self, ctx: Context) -> bool:
    if ctx.text.startswith("повторяй за мной"):
        await ctx.say(ctx.text.removeprefix("повторяй за мной"))
        return True  # фраза обработана, дальше не идёт
    return False
```

## Инструменты для LLM: `@tool`

Метод с `@tool` становится инструментом (function calling), который языковая модель вызывает
сама, когда это нужно для ответа. JSON-схема строится из аннотаций типов.

```python
from typing import Annotated, Literal


@tool("Узнать погоду в городе")
async def get_weather(
    self,
    city: Annotated[str, "Название города"],
    day: Literal["today", "tomorrow"] = "today",
) -> str:
    return f"В городе {city} +5, облачно"
```

- Описание параметра задаётся через `Annotated[тип, "описание"]`.
- Можно возвращать `str`, `dict`/`list` (уйдёт в JSON) или pydantic-модель.
- Чтобы получить контекст разговора, добавьте параметр `ctx` (в схему он не попадает).
- `@tool(..., dangerous=True)` — модель спросит пользователя голосом перед вызовом.
- Имя инструмента для модели: `<плагин>__<метод>`.

Хорошее правило: `@command` — для частых коротких фраз (работает мгновенно и без LLM),
`@tool` — чтобы модель могла использовать навык в свободном разговоре («поставь таймер
на время варки яиц»).

## Контекст `ctx`

| Атрибут / метод | Что делает |
|---|---|
| `await ctx.say(text, emotion=None)` | Сказать фразу (ждёт окончания речи; `wait=False` — не ждать) |
| `await ctx.ask(question, timeout=None)` | Задать вопрос и получить ответ пользователя без имени ассистента; `None` при таймауте |
| `await ctx.confirm(question)` | Вопрос «да/нет» → `bool` |
| `await ctx.set_emotion("joy")` | Эмоция аватара: `neutral`, `joy`, `thinking`, `surprise`, `sad`, `angry` |
| `await ctx.notify(title, text, level)` | Всплывающее уведомление в интерфейсе |
| `ctx.config` | Настройки плагина (словарь) |
| `ctx.storage` | Хранилище ключ-значение плагина |
| `await ctx.llm.complete(prompt, system=...)` | Разовый запрос к языковой модели; `ctx.llm.available` — подключена ли она |
| `ctx.text`, `ctx.source` | Исходная фраза и откуда она пришла (`voice`, `text`, `ui`) |
| `ctx.user_address`, `ctx.assistant_name` | «сэр», «Aion» |
| `ctx.log` | Логгер (loguru) с именем плагина |

Те же `say`, `notify`, `set_emotion`, `config`, `storage`, `llm`, `log` есть у самого плагина
(`self.…`). Через них плагин может говорить сам, без запроса пользователя, например по таймеру.

## Жизненный цикл и фоновые задачи

```python
class Watcher(Plugin):
    async def on_load(self) -> None:  # после загрузки и после каждой перезагрузки
        self.create_task(self.poll())  # задача отменится сама при выгрузке плагина

    async def poll(self) -> None:
        while True:
            if await self.something_happened():
                await self.say("Сэр, у нас гости.")
            await asyncio.sleep(60)

    async def on_unload(self) -> None: ...  # перед выгрузкой/перезагрузкой
    async def on_wake(self) -> None: ...  # пользователь назвал имя ассистента
    async def on_settings_changed(self) -> None: ...  # настройки изменены в интерфейсе
    async def on_shutdown(self) -> None: ...  # ассистент завершает работу
```

Запускайте фоновую работу только через `self.create_task(...)`: при горячей перезагрузке
такие задачи корректно останавливаются.

## Реплики по событиям: `react`

`self.say()` говорит сразу и дословно. Если плагин следит за чем-то (игра, почта, сборка) и хочет,
чтобы ассистент *отреагировал*, сообщите о событии через `self.react()`: ассистент сам решит,
стоит ли говорить, и сформулирует реплику в характере персонажа, с учётом истории диалога.

```python
self.react(
    "Пользователь сделал эйс в CS2",  # что случилось (для LLM), а не что сказать
    importance=1.0,  # 0..1; что ниже порога «болтливости», отбрасывается
    key="ace",  # события с одним ключом делят cooldown
    cooldown=30,  # не повторять этот ключ N секунд
    ttl=8,  # не говорить, если момент упущен (ждали дольше N секунд)
    quick=["Эйс!"],  # готовые фразы: без LLM, если она медленная или выключена
    emotion="joy",  # эмоция аватара для готовой фразы
)
```

- Реплика не перебивает пользователя и ассистента: она ждёт тишины. Между репликами выдерживается
  пауза, зависящая от болтливости; события с `importance >= 0.9` её пропускают.
- События, пришедшие одной пачкой (три килла за секунду), превращаются в одну реплику.
- Реплика попадает в историю диалога, поэтому на вопрос «а что случилось?» ассистент ответит.
- Болтливость и прочее настраиваются на странице «LLM» → «Комментарии к событиям».

Для игр с Game State Integration (CS2, Dota 2) есть `aion.sdk.serve_json(port, handler)` —
приёмник JSON на локальном порту, и `aion.sdk.games` — поиск игр Steam, запись GSI-конфига,
подсчёт серий раундов. Примеры — встроенные плагины `cs2`, `dota2`, `valorant`.

## Настройки плагина

Объявите настройки в `plugin.yaml`, и на странице «Плагины» появится форма:

| `type` | Поле | Дополнительно |
|---|---|---|
| `string` | строка | |
| `text` | многострочный текст | |
| `int`, `float` | число или ползунок (если заданы `min` и `max`) | `min`, `max` |
| `bool` | переключатель | |
| `enum` | выпадающий список | `options: [a, b]` |
| `secret` | пароль: в интерфейсе не показывается | `env: NAME` — взять из переменной окружения |

Значения хранятся в `config.yaml` → `plugins.settings.<имя>`, в коде доступны как
`self.config["key"]`.

## Хранилище

```python
count = await self.storage.get("count", 0)
await self.storage.set("count", count + 1)  # любые JSON-совместимые значения
await self.storage.delete("count")
everything = await self.storage.all()
```

Данные лежат в SQLite (`%LOCALAPPDATA%\Aion\aion.db`) и переживают перезапуск.
Для своих таблиц есть `self.host.db` (`execute`, `fetchall`, `fetchone`).

## Зависимости

Пакеты из `dependencies` ставятся автоматически при первой загрузке плагина в отдельную папку
`%LOCALAPPDATA%\Aion\plugin_deps\<имя>` (через `uv pip install --target` или `pip`) и
подключаются только для плагинов. Тяжёлые модули импортируйте внутри функций: так плагин
загружается быстрее, а ошибка импорта не мешает остальным командам.

Ограничение: все плагины работают в одном процессе, поэтому две разные версии одной библиотеки
у двух плагинов не уживутся.

## Опасные действия и права

- `@command(..., dangerous=True)` и `@tool(..., dangerous=True)` перед выполнением спрашивают
  голосом: «Сэр, подтвердите: выключить компьютер?». Без ответа действие отменяется.
- `permissions` в `plugin.yaml` показываются пользователю при установке и на странице плагинов.
  `system`, `shell` и `files` подсвечиваются как опасные.

> **Важно:** права — это декларация, а не песочница. Плагин выполняется с правами
> пользователя, как любая программа. Устанавливайте плагины только из источников, которым доверяете.

## Установка и распространение

```powershell
uv run aion plugin install C:\path\to\my_plugin          # папка
uv run aion plugin install my_plugin.zip                 # архив (можно с папкой внутри)
uv run aion plugin install https://github.com/me/aion-weather.git
uv run aion plugin list
uv run aion plugin disable weather
uv run aion plugin enable weather
uv run aion plugin remove my_plugin
```

То же самое есть на странице «Плагины» в интерфейсе. Чтобы поделиться плагином, опубликуйте
папку в git-репозитории или как zip-архив.

## Примеры

- `user_plugins/coin` — монетка, кубик, уточняющий вопрос `ctx.ask`, хранилище, настройки, инструмент.
- `builtin/timers` — фоновые задачи, напоминания, переживающие перезапуск, разбор «через полчаса».
- `builtin/weather` — HTTP-запросы, настройки, инструмент для LLM.
- `builtin/homeassistant` — интеграция с внешней системой, секрет-токен, отказ от фраз
  (`return False`), выключен по умолчанию.
- `builtin/clipboard` — использование LLM внутри команды (`ctx.llm.complete`).
- `builtin/calc` — плагин из нескольких модулей (`from .units import ...`).
- `builtin/cs2`, `builtin/dota2`, `builtin/valorant` — реплики по событиям игры (`react`), HTTP-приёмник, опрос локального API.

## Советы

- Отвечайте коротко: ответ звучит голосом. Числа можно писать цифрами, символы `°`, `%`, `м/с`
  и время `18:30` синтезатор прочитает правильно.
- Думайте, как фразу услышит распознаватель: добавьте варианты (`(открой|запусти)`)
  и необязательные слова (`[мне]`).
- Если команда может перехватить чужие фразы, возвращайте `False`, когда она «не ваша».
- Ошибки ловить не обязательно: исключение в обработчике будет залогировано,
  а пользователь услышит «при выполнении команды произошла ошибка».
- Логи плагина видны на странице «Логи» и в `%LOCALAPPDATA%\Aion\logs\aion.log`.
- Тестируйте без микрофона: `uv run aion text`.
