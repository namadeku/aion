# Голосовой ввод: что изменено и почему

Цепочка: микрофон → VAD (Silero) → сегментация → STT (faster-whisper) → имя ассистента → роутер.
Измеряется скриптом `scripts/bench_stt.py` на наборе фраз `tests/data/voice/phrases.yaml`
(WAV генерируются Piper локально в `tests/data/voice/wav/`, в git не попадают):

```bash
uv run python scripts/bench_stt.py --device cpu  --pace 1 --label run-cpu
uv run python scripts/bench_stt.py --device cuda --pace 1 --label run-cuda
```

`--pace 1` подаёт звук в реальном времени (нужно для честной задержки «конец фразы → текст»),
`--stt-only` пропускает конвейер (быстрый подбор параметров Whisper), `--set секция.поле=значение`
переопределяет настройки. Набор: 83 клипа (команды с именем в вариантах clean / noise 8 дБ /
echo / fast ×1,5 / quiet, болтовня без имени, слова, похожие на имя, собственный голос
ассистента, тишина и шум для проверки галлюцинаций). Машина: RTX 4060, CPU Whisper small int8,
GPU large-v3-turbo float16.

## Базовая линия (до изменений)

| Метрика | CPU (small) | CUDA (turbo) |
|---|---|---|
| WER STT, все клипы / CER | 45,7 % / 33,4 % | 48,6 % / 38,5 % |
| Wake precision / recall | 0,939 / 0,78 | 0,949 / 0,627 |
| Ложные срабатывания | 3 (`ион натрия`, `эй, он опять`, имя в речи ассистента) | 2 |
| Точность роутера по командам | 52,7 % | 52,7 % |
| Задержка «конец фразы → текст», p50 / p95 | 2075 / 3109 мс | 735 / 1547 мс |
| Галлюцинации на шуме (из 3) | 2 («айон, айон, …» ×50) | 1 |

Выводы из базовой линии: промпт с именем вызывает циклы «айон, айон…» на шуме; имя засчитывается
в любом месте начала фразы и в «ион»/«эй он»; собственный голос с именем будит ассистента;
фразы поверх эха (variant echo) не распознаются вообще; p95 задержки раздувает температурный
fallback Whisper.

## До / после (pace 1, 83 клипа)

| Метрика | CPU до | CPU после | CUDA до | CUDA после |
|---|---|---|---|---|
| Wake precision | 0,939 | 1,0 | 0,949 | 0,979 |
| Wake recall | 0,78 | 0,797 | 0,627 | 0,78 |
| Ложные срабатывания | 3 | 0 | 2 | 1 (`ион натрия`, фонетически неотличимо) |
| Точность роутера | 52,7 % | 60,0 % | 52,7 % | 67,3 % (без variant echo 84 %) |
| WER команды в конвейере | 57,4 % | 49,7 % | 51,3 % | 36,4 % |
| Задержка p50 / p95, мс | 2075 / 3109 | 2003 / 4030 | 735 / 1547 | 713 / 935 |
| Галлюцинации на шуме (из 3) | 2 | 0 | 1 | 0 |

Что осталось нерешённым: фразы поверх собственного голоса ассистента (variant echo) не
распознаются без аппаратного/программного AEC (11 из 11 пропущено) - нужны наушники или AEC;
Whisper иногда вообще не пишет быстро сказанное имя.

## Что изменено

- Имя: фонетическая свёртка + Levenshtein (`wakeword/names.py`), только в начале фразы
  (после слов-вставок «слушай», «эй»), чёрный список похожих слов («ион», «лион», «неон»),
  запятая разделяет «эй, он», хвостовое имя («который час, Аион») только если роутер знает команду.
- Эхо: `audio/echo.py` - транскрипт из слов собственной речи не считается обращением; хвост
  после воспроизведения 0,6 с.
- Whisper: одна температура (нет повторных проходов), beam 5 на CUDA, greedy на CPU, прогрев
  при старте, фильтр тишины по пику, фильтр циклов и расширенный список галлюцинаций.
- Звук: нормализация уровня тихих фраз (до +30 дБ), опциональный спектральный гейт.
- Текст: `text/asr.py` - словарь типичных ошибок, порядковые даты.
- Опционально `audio.speculative_ms`: распознавание стартует после короткой паузы.

(Раздел будет дополнен результатами speculative и контрактом для страницы «Микрофон».)

## Speculative recognition (`audio.speculative_ms`, по умолчанию 250)

Распознавание стартует после 250 мс тишины, не дожидаясь закрытия фразы (500 мс); результат
используется, если речь не возобновилась. CUDA, pace 1: задержка p50 / p95 713 / 935 -> 440 / 627 мс
при той же точности (роутер 67,3 %).

## Контракт для страницы «Микрофон» (поля конфига, читаются через getattr с безопасными значениями)

| Поле | Тип / умолчание | Описание |
|---|---|---|
| `stt.whisper_model` (есть) | str, auto | выбор модели |
| `audio.vad.threshold` (есть) | 0..1, 0.5 | порог VAD, применяется на лету |
| `audio.vad.min_silence_ms` (есть) | int, 500 | пауза конца фразы, на лету |
| `audio.normalize` | bool, true | подъём уровня тихой речи |
| `audio.denoise` | bool, false | спектральный гейт |
| `audio.speculative_ms` | int 0..400, 250 | ранний старт STT, 0 - выкл. |
| `audio.echo_holdoff_s` | float, 0.6 | хвост после своей речи |
| `stt.beam_size` | int, 0 | 0 = авто (5 на CUDA, 1 на CPU) |
| `stt.compute_type` | str, auto | float16/int8/... |
| `stt.cpu_threads` | int, 0 | потоки CPU |
| `stt.bias` | prompt/hotwords/none, prompt | подсказка имени декодеру |
| `stt.postprocess` | bool, true | словарь ошибок |
| `stt.corrections` | dict[str,str], {} | пользовательский словарь ошибок |
| `wakeword.tail_name` | bool, true | имя после команды |
| `wakeword.tail_check_max_s` | float, 0 (авто) | окно проверки хвостового имени |

Push-to-talk уже есть (`VoicePipeline.push_to_talk()`, горячая клавиша). Режим «только PTT» —
`wakeword.backend: none` + `activate()`; нового API не нужно.
